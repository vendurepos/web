MedusaPOS is an open source point of sale application for [MedusaJS](https://medusajs.com).

Built on [TallyUI](https://github.com/TallyUI/tallyui) — composable UI primitives for POS systems.

## Features

- **Multi-platform** — iOS, Android, Web, and Desktop from a single codebase
- **Local-first** — Works offline with RxDB, syncs when connected
- **Modular** — Built on TallyUI's composable architecture
- **Open source** — MIT licensed

## Status

MedusaPOS is currently in **beta**. We're working toward an MVP release.
