- Pre-release: expect changes before 1.0.

- Web till only for now.

- Refunds: not yet.

- Coupon codes: not yet.
  Line and order discounts work at the till.

- Card payments are taken on a separate terminal and confirmed on the till.
  The till does not talk to the terminal.

- Prices and stock: an open till picks up a price change within about a minute
  and a stock change within about five minutes.

- Sales take stock from the channel's default stock location.
  The till cannot pick a location.

- One browser tab per till.

- Private browser windows that give a site no storage,
  such as Safari's, cannot run the till.

- The manager's approval on register close is a typed name,
  not a verified sign-in.

- Postgres only.
  MySQL, MariaDB and SQLite are not supported.

- Device keys need plugin 0.2.0 or later, which is not yet on npm;
  see [Plugin setup](/docs/plugin-setup).
